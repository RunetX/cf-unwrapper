# Формат выгрузки 2.20 (платформа 8.3.27) из 2.21 (8.5): что меняется при понижении.
# Выведено сверкой выгрузок БП 3.0.107 (режим совместимости 8.3.16) платформами 8.3.24, 8.3.27 и 8.5.1, 29.10.2026.
#
# Правила (по строке; `in A|B/C` — родитель элемента, суффикс пути):
#   absent  Э [in Р] [= з1|з2]   элемента в формате нет: значения из списка опускаются, прочие — ошибка
#   default Э [in Р] = з         формат не пишет значение по умолчанию
#   value   Э [in Р] = нов > стар   значение переименовано (`*:x` — с любым префиксом)
#   rename  Э [in Р] > Стар      элемент переименован
#   insert  Э in Р = з [unless Э2|Э3] before Э4|Э5   формат пишет элемент, которого у 2.21 нет
#   attr-drop Э|* атрибут        атрибута в формате нет
#   refuse  Э has подстрока       по тексту 2.21 не выразить — ошибка файла (выгрузка из .cf пишет это сама)
#
# Значения в `absent` — те, что встретились в конфигурации, выгруженной 8.3.24: платформа 8.5 выводит их из
# других свойств. Другое значение — свойство задано в 8.5 явно, в 2.17 его не выразить, и выгрузка отказывает.
