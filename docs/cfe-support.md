# Расширения конфигурации

Реализован цикл CFE → XML → CFE. Он проверен 4 ноября 2026 года на
Контур.КЭДО для ЗУП 1.27.3 через платформу 1С 8.5.1.1529.
Для преобразования самой Развёртке платформа и информационная база не нужны.

```powershell
cf-unwrapper export extension.cfe extension-xml
cf-unwrapper import extension-xml rebuilt.cfe
```

Каталог выгрузки должен быть новым или пустым. При неподдержанном свойстве
загрузчик сообщает отказ; неполная загрузка не записывается в CFE.

## Возможности и границы

- Корень расширения читается из `configinfo`; результат собирается в один
  W32-контейнер CFE с SHA-1 сжатых записей, без служебных частей обычного CF.
- Сохраняются назначение расширения, префикс, совместимость, сопоставление по
  внутренним идентификаторам, `ObjectBelonging` и состояния `xr:PropertyState`.
- У заимствованных объектов сохраняются выбранные свойства и расширяемые
  модули, командный интерфейс, содержимое подсистем и рабочая область.
  Неизвестные GUID свойств, состояния и неподдержанные ссылки вызывают отказ.
- Обратная запись заимствованных объектов реализована для Configuration,
  Catalog, Document, CommonModule, InformationRegister, Language и Subsystem
  в режиме совместимости расширения `Version8_3_16`.
  Другие классы заимствованных объектов и режимы требуют отдельной проверки;
  проверка одного расширения не гарантирует поддержку любого CFE.
- Собственные объекты используют существующие преобразователи метаданных,
  форм, модулей и макетов. Добавлены дополнительные индексы с путями к
  собственным реквизитам, измерениям и ресурсам таблицы; другие пути отклоняются.
- Доработаны свойства форм версии 59: независимые отметки незаполненного
  поля, линии и чередование строк, заголовки групп, активация строки, панель
  иерархии, ширина в таблице, переключатели, картинки и уникальность команды.
  `AutofillHint` и `OnScreenKeyboardReturnKeyText` записываются независимо.
  Защитная проверка неизвестных хвостовых полей форм сохранена.

## Приёмка на КЭДО

Исходный контейнер содержит 2013 записей и 741 объект верхнего уровня.
Эталон получен командой `ibcmd config export --file=<original.cfe>`.
Сравниваются относительные имена и содержимое файлов, а не двоичные CFE:
в контейнере меняются временные метки и способ сжатия.

| Проверка | Результат |
|---|---|
| CFE → XML движком против XML исходного CFE от платформы | 2453/2453 файла, побайтово |
| Загрузка XML движком | 2012 записей + `configinfo`, без отказов |
| CFE → XML движком → CFE движком → XML платформой | 2453/2453 файла исходного эталона, побайтово |
| Формы в итоговой проверке | 290/290 |
| Дополнительные индексы в итоговой проверке | 2/2 |
| Собственный синтетический CFE → XML платформой | 7/7 файлов контрольной синтетики |

Отдельно выполнен контрольный XML → CFE → XML самой платформой. Он изменяет
151 форму и два файла модулей относительно её первой выгрузки. Этот контроль
сохранён для диагностики; результат Развёртки сравнивается с исходной выгрузкой
и сохраняет все её 2453 файла, включая эти различия.

Локальные доказательства: `local/kedo-final-diff.txt`,
`local/kedo-roundtrip-v7.log`, `local/kedo-roundtrip-v7-platform.log`,
`local/kedo-roundtrip-v7-original-diff.txt`, `local/kedo-control-diff.txt`,
`local/kedo-check-final.log` (`check: PASS`).
Корпоративный CFE, XML, BSL и ресурсы находятся только в исключённом `local/`
и исходном каталоге пользователя; в исходники и пакет они не включаются.

## Происхождение и регрессия

Таблица GUID свойств сверена с моделью MdProperty установленной EDT и XML
платформы. Позиции сопоставления идентификаторов и уникальности команды
проверены отдельными опытами с изменением одного свойства XML. Раздельные
слоты подсказки автозаполнения и клавиши экранной клавиатуры проверены по
записям контрольной загрузки платформы и закреплены регрессионным тестом.

`src/xml/imp/extension_defaults.rs` содержит структурные значения по умолчанию
из специально созданного синтетического расширения платформы 8.5.1.1529.
Имена и идентификаторы синтетики собственные; корпоративные записи не служат
шаблонами. Семь XML-файлов в `tests/fixtures/extension` — публичная синтетика,
проверенная независимой загрузкой и выгрузкой платформы.

Автоматические тесты проверяют заимствование, отказ на неизвестном состоянии,
совместимость, упаковку CFE, XML-круг синтетики и дополнительные индексы.
Общая команда `python tools/check.py` также выполняет аудит ресурсов,
регрессию CF/EPF и настоящую проверку `cargo package`.
