Развёртка теперь умеет **выгружать расширения 1С в XML и собирать их обратно в CFE** с сохранением заимствованных объектов и расширяемых свойств.

Поддержку проверили на **Контур.КЭДО для ЗУП 1.27.3**. Исходное расширение прошло полный цикл:

```text
CFE → XML Развёрткой → CFE Развёрткой → XML платформой 1С
```

Платформа 8.5.1.1529 приняла собранный CFE. Повторная выгрузка совпала с XML исходного расширения **побайтово: 2453 из 2453 файлов**, включая 290 форм, дополнительные индексы, модули и ресурсы.

### Попробовать

Скачайте **cf-unwrapper.exe** или ZIP с инструкцией и откройте PowerShell:

```powershell
.\cf-unwrapper.exe export .\extension.cfe .\extension-xml
.\cf-unwrapper.exe import .\extension-xml .\rebuilt.cfe
```

Для этих операций не нужны Rust, установленная платформа или информационная база. Каталог выгрузки должен быть новым или пустым.

### Что изменилось

- Сохраняются признаки заимствования, выбранные свойства, расширяемые модули и командный интерфейс.
- Добавлены дополнительные индексы регистров и недостающие типы менеджеров.
- Доработаны свойства форм: заголовки групп, линии таблиц, активация строки, панель иерархии, переключатели, картинки, подсказки автозаполнения и уникальность команд.
- Добавлены синтетические регрессионные тесты и проверка точных хешей тестовых XML.

Проверенный режим совместимости расширения — **8.3.16**. Обратная запись заимствованных объектов поддержана для Configuration, Catalog, Document, CommonModule, InformationRegister, Language и Subsystem. Поддержка произвольного расширения не гарантируется; неизвестные свойства и неподдержанные структуры вызывают явный отказ. При отказах импорта результат не создаётся и не заменяется.

### Скачать и проверить

- **cf-unwrapper.exe** — готовая утилита Windows x64.
- **cf-unwrapper-v0.2.0-windows-x86_64.zip** — утилита, инструкция, лицензия и документация поддержки расширений.
- **SHA256SUMS.txt** — контрольные суммы EXE и ZIP.

Локально прошли `python tools/check.py`: аудит ресурсов, форматирование, тесты CF/EPF/CFE и настоящий `cargo package verify`. Готовый EXE отдельно проверен с PATH только из Windows System32: создание обработки, круг EPF ↔ XML, XML 2.20/2.17 и круг синтетического CFE — PASS. Проверены состав ZIP и контрольные суммы. Корпоративный CFE и его содержимое в исходники, тесты и релиз не включены. В поставке используются собственные синтетические примеры.
